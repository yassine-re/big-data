# Partie 1 - Interface d'analyse

Ce dossier contiendra le premier livrable du sujet.

## Attendus

- un dossier présentant le besoin, les sources, l'architecture justifiée, les
  traitements, les indicateurs, les visualisations, les limites et les recommandations ;
